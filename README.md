# Colonies Alive

An addon for [MineColonies](https://www.curseforge.com/minecraft/mc-mods/minecolonies) (Minecraft 1.21.1, NeoForge) that brings the colony to life: children play, cry and go to school, adults chat and fall in love, babies are born, crawl and get carried to bed, and citizens' moods show in how they walk.

See [release/DESCRIPTION.md](release/DESCRIPTION.md) for the full feature list and [release/CHANGELOG.md](release/CHANGELOG.md) for changes.

## Building

Requires JDK 21.

```
./gradlew build
```

The jar ends up in `build/libs/`. `./gradlew runClient` starts a test client; MineColonies and its dependencies are downloaded from the LDT Team maven.
